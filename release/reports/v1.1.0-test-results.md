## Defects found and fixed during this work

1. **Login case-sensitivity** (client-impacting; reproduced on the delivered 1.0.2 build).
2. Fresh-install login answered "wrong credentials" instead of "not set up".
3. **Introduced and caught by tests:** stacked unnamed throttles shared one counter, so polling setup status could lock out recovery (429). Fixed with named limiters + regression test.
4. Diagnosis mode crashed when the logs folder did not yet exist. Fixed.
